# 【よみとく5分】引き継ぎメモ（2026-11-18）

- 対象・単元：小学1〜6年（国語・読解）。リーディングスキルテスト（RST）の6分野7項目の考え方をもとにした、毎日5分程度の読解トレーニング（電子黒板に表示して学級全体で行う）
- できていること：
  - 学年帯（低・中・高）各50問、7つの問題タイプを順番に出題
  - ステップ：範読を聴く → 黙読 → 音読 → ノートに写す（視写）→ となりと交換 → 字数を数える → 問いに答える → 答え合わせ
  - 実施記録・タイプ別正答率・カレンダー、問題の追加、JSONの書き出し／読み込み
- 決めた仕様（理由も一言）：
  - 視写は「1分＋続き30秒」。1分で音が鳴り、指示が「今書いたところに『／』の印をつける → 切りのよいところまで写す」に変わる（あとで1分間に正しく書けた字数を数えるため）。時間は設定で変えられる（続きの時間は sec.shisha2）
  - 視写はいつも全文を写す（時間で区切るので、速い子も書き終わらないようにする）。「写す範囲」の設定はなくした
  - 視写のあとに「となりと交換」（60秒：まちがい・読めない字に赤えんぴつで印）と「字数を数える」（30秒：「／」までに正しく書けた字数）のステップを追加。字数は記録しない
  - 1文の文字数の目安は「学年×10〜15字」。学年帯の幅で、低学年10〜30字・中学年30〜60字・高学年50〜90字に全問をそろえた（根拠の文字列・正解は変えていない）
  - 既定の合計時間は6:30（以前は5:00）
  - 設定の保存形式に v:2 を追加。以前の既定値（視写90秒）のままの端末は、読み込み時に60秒へ移行する
- 未解決・次にやること：
  - 合計が5分をこえたので、各ステップの時間配分を実際の授業で確かめる
  - 字数を数えるとき、句読点を1字に数えるかを決める
  - 「問題を追加」で入れる問題にも、文字数の目安の確認（警告）を入れるか検討

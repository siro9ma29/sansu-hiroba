使い方

  1. 右上で学年帯を選びます（低・中・高、各50問）。
  2. 「はじめる」を押すと、今日の問題を電子黒板やテレビに大きく表示します。問題タイプは毎回順番に入れ替わります。
  3. 画面の指示に合わせて、範読を聴く → 黙読 → 音読 → ノートに写す → となりと交換 → 字数を数える → 問いに答える → 答え合わせと進めます。本文は最後まで表示したままです。
  4. ノートに写す（視写）は、本文の全文を写します。1分たつと音が鳴って画面の指示が変わるので、子どもは書いたところに「／」の印をつけ、続く30秒で切りのよいところまで写します。そのあと、となりの人とノートを交換して、まちがいや読めない字に赤えんぴつで印をつけ、ノートを戻して「／」までに正しく書けた字数を数えます。
  5. 子どもは答えの番号をノートに書きます。答え合わせでは、正解と本文中の根拠が黄色く表示されます。
  6. 正解した人数を入れて「記録して終わる」を押すと、実施記録に残ります（人数は入れなくても大丈夫です）。

操作のヒント

  • キーボード：→ 次へ、← もどる、スペース タイマーの一時停止・再開
  • 文字の大きさは「A−」「A＋」で変えられます。
  • 読み上げは補助機能です。範読は先生が読むことをおすすめします（端末によっては日本語の音声が使えない場合があります）。
  • ステップの時間や、使わないステップは「設定」で変えられます。
